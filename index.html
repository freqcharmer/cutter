Selection

Arrange

Right-click (or press and hold) anything for more.

Edit nodes

Drag nodes and handles. Double-click a line to add a node, or a node to switch corner and smooth. Shift-click or drag a box to pick several. Alt-drag a handle to make a corner. Arrow keys nudge.

Text

Script fonts overlap from letter to letter. Keep Weld letters on so the word cuts as one piece.

Offset

Trace

Darker pixels than the threshold become cut lines. A sharp, high-resolution logo traces best.

Color layers

    Click a layer to select everything in it. Change the swatch to recolor the layer. In the Cut window, "One color at a time" cuts each layer on its own vinyl.
